# Codex Instructions for One More Drink

You are helping build One More Drink, a React Native Expo TypeScript app.

Follow these rules:

1. Work in small, reviewable changes.
2. Do not implement large unrelated features in one pass.
3. Before making major changes, summarize the intended files and approach.
4. Prefer simple, maintainable code over clever abstractions.
5. Use TypeScript strictly and avoid `any` where practical.
6. Keep user data local for MVP.
7. Do not add backend services unless explicitly requested.
8. Do not add authentication unless explicitly requested.
9. Keep the tone of user-facing copy calm, supportive, and non-judgmental.
10. After making changes, summarize what changed and what should be tested.
